## 🌷 Sobre o Projeto

Um espaço digital desenvolvido para transmitir aconchego, sofisticação e confiança. O projeto conecta as clientes ao **Studio Renata Veras**, permitindo conhecer os procedimentos de estética e micropigmentação, tirar dúvidas rápidas no WhatsApp e se cadastrar para benefícios exclusivos.

Conta também com uma **área administrativa privativa** para gerenciar os contatos recebidos com total carinho e praticidade.

---

## 🪄 Funcionalidades com Toque Especial

- 🌿 **Experiência Visual Imersiva**: Design elegante em tons de rosa suave e dourado, tipografia refinada e animações sutis.
- 💬 **Atendimento Humanizado no WhatsApp**: Botão flutuante pulsante e links diretos em cada serviço com mensagens pré-configuradas.
- 📋 **Formulário de Pré-Agendamento**: Captura de leads com validação de telefone e consentimento de privacidade (LGPD).
- 🔐 **Painel Administrativo VIP**: Listagem, busca, métricas e exportação de cadastros em CSV.
- 📱 **Totalmente Responsivo**: Criado com amor para funcionar perfeitamente no celular, tablet e computador.

## 🎀 Estrutura do Projeto

```
Veras/
├── 🌸 frontend/                 # Interface em React + Vite
│   ├── src/
│   │   ├── assets/              # Logos, ícones e ilustrações delicadas
│   │   ├── components/          # Hero, Serviços, Depoimentos, Formulário, WhatsApp
│   │   ├── pages/               # LandingPage, LoginPage, AdminPage
│   │   └── config/              # Parâmetros e constantes
│   └── index.html
│
├── ☕ backend/                  # API REST em Spring Boot (Java)
│   ├── src/main/java/           # Model, Repository, Controller e Security
│   └── src/main/resources/      # Configuração da aplicação
│
└── 📄 schema.sql                # Estrutura do banco de dados (Supabase / Postgres)
```

## 💻 Como Rodar o Projeto com Carinho

### 1. Frontend (Interface)

```bash
cd frontend
npm install
npm run dev
```
> Acesse: `http://localhost:5173` 🌷

### 2. Backend (Serviço de Dados)

```bash
cd backend
./mvnw spring-boot:run
```
> API disponível em: `http://localhost:8080` ☕
